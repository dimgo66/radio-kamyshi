# Radio Kamyshi

Веб-приложение для интернет-радиовещания "Radio Kamyshi". Проект включает серверную часть для управления треками, плейлистами и эфиром, а также веб-интерфейс для администраторов и слушателей.

## Описание проекта

Radio Kamyshi - это комплексное решение для онлайн-радиостанции, позволяющее:
- Управлять музыкальными треками и плейлистами
- Планировать и вести прямые трансляции
- Создавать программы и расписания вещания
- Вести автоматическое вещание по заданному расписанию
- Предоставлять аудиторию для прослушивания эфира

## Структура проекта

Проект состоит из следующих основных компонентов:

### Backend (FastAPI)
- **app/** - основной код приложения
  - **api/** - REST API эндпоинты
  - **core/** - основные компоненты и конфигурация
  - **crud/** - операции с базой данных
  - **db/** - настройки подключения к БД
  - **models/** - модели данных SQLAlchemy
  - **schemas/** - схемы Pydantic для валидации
  - **tasks/** - фоновые задачи (Celery)
  - **utils/** - вспомогательные функции
- **alembic/** - миграции базы данных
- **tests/** - тесты

### Frontend (React + TypeScript)
- **src/** - исходный код
  - **components/** - компоненты React
  - **pages/** - страницы приложения
  - **services/** - сервисы для работы с API
  - **store/** - управление состоянием
  - **hooks/** - пользовательские хуки
  - **utils/** - вспомогательные функции

## Установка и запуск

### Требования
- Docker и Docker Compose
- Python 3.13+ (для локальной разработки)
- Node.js 16+ (для локальной разработки фронтенда)

### Запуск с использованием Docker

1. Клонировать репозиторий:
```bash
git clone https://github.com/yourusername/radio-kamyshi.git
cd radio-kamyshi
```

2. Создать файл с переменными окружения:
```bash
cp .env.example .env
```

3. Отредактировать .env файл, указав нужные параметры

4. Запустить проект с помощью Docker Compose:
```bash
docker-compose up -d
```

5. Применить миграции базы данных:
```bash
docker-compose exec backend alembic upgrade head
```

6. Создать суперпользователя:
```bash
docker-compose exec backend python -m app.initial_data
```

7. Приложение будет доступно по адресу http://localhost:8080

### Локальная разработка

#### Backend
1. Создать и активировать виртуальное окружение:
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate  # Windows
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Запустить приложение в режиме разработки:
```bash
uvicorn app.main:app --reload
```

#### Frontend
1. Установить зависимости:
```bash
cd frontend
npm install
```

2. Запустить в режиме разработки:
```bash
npm run dev
```

## Компоненты системы

Проект состоит из нескольких основных компонентов:

1. **Backend (FastAPI)** - API сервер для управления всеми операциями
2. **Frontend (React)** - Пользовательский интерфейс для управления контентом и мониторинга
3. **Icecast** - Сервер для трансляции аудио
4. **PostgreSQL** - База данных
5. **Redis** - Кэширование и очереди сообщений
6. **Celery** - Обработка фоновых задач

## Основные возможности

- Управление аудио-треками (загрузка, редактирование, организация)
- Создание и управление плейлистами
- Планирование и расписание программ
- Прямая трансляция аудио через Icecast
- Аутентификация и авторизация пользователей с разными уровнями доступа
- Мониторинг состояния трансляции в реальном времени
- Аналитика слушателей

## Запуск проекта

Проект настроен для запуска через Docker Compose:

```bash
# Запуск всех компонентов
docker-compose up -d

# Остановка
docker-compose down
```

Для локальной разработки можно запустить компоненты отдельно:

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
