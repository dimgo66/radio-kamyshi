
# ✅ Задания для проекта "Камыши" — интернет-радио

- [ ] Инициализировать репозиторий проекта (`git init`)
- [ ] Создать папки: `backend/`, `frontend/`, `media/`, `playlists/`, `scheduler/`

- [ ] Создать модель `Program`: имя, плейлист, дата/время начала
- [ ] Настроить PostgreSQL и Alembic/ORM
- [ ] Реализовать загрузку треков (сохранение файлов и данных)
- [ ] Реализовать редактирование треков
- [ ] Реализовать создание и редактирование плейлистов
- [ ] Реализовать создание программ и их планирование
