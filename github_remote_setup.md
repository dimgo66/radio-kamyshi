# Настройка удаленного репозитория на GitHub

## 1. Создайте новый репозиторий на GitHub

Перейдите на сайт GitHub (https://github.com) и создайте новый репозиторий со следующими настройками:
- Имя репозитория: radio-kamyshi
- Описание: Веб-приложение для интернет-радиовещания "Radio Kamyshi". Бэкенд (FastAPI) и фронтенд (React) для управления и вещания аудиоконтента.
- Видимость: Public
- Не инициализируйте репозиторий с README, .gitignore или лицензией

## 2. Свяжите локальный репозиторий с удаленным

После создания репозитория выполните следующие команды в терминале:

```bash
# Добавить удаленный репозиторий
git remote add origin https://github.com/ВАШ_ЛОГИН/radio-kamyshi.git

# Изменить URL, если вы используете SSH
# git remote add origin git@github.com:ВАШ_ЛОГИН/radio-kamyshi.git

# Отправить коммиты на GitHub
git push -u origin main
```

Если у вас возникнут проблемы с аутентификацией, вам может потребоваться:
1. Настроить SSH-ключи для GitHub
2. Или использовать GitHub CLI для аутентификации

## 3. Проверка статуса

```bash
# Проверьте статус удаленного репозитория
git remote -v
```

## 4. После успешной отправки

После успешной отправки кода на GitHub вы можете удалить этот файл инструкций:

```bash
rm github_remote_setup.md
```
