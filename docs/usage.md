# Руководство пользователя "Радио Камыши"

## Введение

"Радио Камыши" - система для управления онлайн-радиостанцией. Она позволяет загружать аудиотреки, создавать плейлисты, планировать эфир и транслировать музыку через Icecast.

## Начало работы

### Вход в систему

1. Откройте веб-браузер и перейдите по адресу радиостанции.
2. На странице входа введите ваш email и пароль.
3. Нажмите кнопку "Войти".

### Главная панель управления

После входа вы попадете на главную панель управления, которая отображает:
- Текущее состояние эфира
- Количество слушателей
- Статистику по прослушиваниям
- Список предстоящих программ

## Управление треками

### Загрузка треков

1. Перейдите в раздел "Треки" в боковом меню.
2. Нажмите кнопку "Загрузить трек".
3. Перетащите аудиофайл в область загрузки или нажмите для выбора файла.
4. Заполните метаданные трека (название, исполнитель, альбом, жанр).
5. Нажмите "Сохранить".

### Редактирование метаданных трека

1. В списке треков найдите нужный трек.
2. Нажмите кнопку "Редактировать" (иконка карандаша).
3. Измените необходимые поля.
4. Нажмите "Сохранить".

### Удаление трека

1. В списке треков найдите нужный трек.
2. Нажмите кнопку "Удалить" (иконка корзины).
3. Подтвердите удаление в диалоговом окне.

## Управление плейлистами

### Создание плейлиста

1. Перейдите в раздел "Плейлисты" в боковом меню.
2. Нажмите кнопку "Создать плейлист".
3. Введите название и описание плейлиста.
4. Нажмите "Сохранить".

### Добавление треков в плейлист

1. Откройте плейлист, нажав на его название в списке плейлистов.
2. Нажмите кнопку "Добавить треки".
3. В появившемся окне выберите треки из списка.
4. Нажмите "Добавить выбранные треки".

### Изменение порядка треков в плейлисте

1. Откройте плейлист.
2. Используйте кнопки со стрелками вверх и вниз для изменения позиции трека.
   - Или перетащите треки с помощью мыши, если эта функция доступна.

### Удаление треков из плейлиста

1. Откройте плейлист.
2. Нажмите кнопку "Удалить" (иконка крестика) рядом с треком.

## Планирование эфира

### Создание программы

1. Перейдите в раздел "Программы" или "Расписание".
2. Нажмите кнопку "Создать программу".
3. Заполните форму:
   - Название программы
   - Описание
   - Дата и время начала
   - Продолжительность
   - Выберите плейлист
4. Нажмите "Сохранить".

### Просмотр расписания

1. Перейдите в раздел "Расписание".
2. Используйте календарь для переключения между датами.
3. Используйте переключатели для изменения представления (день, неделя, месяц).

### Редактирование программы

1. В расписании нажмите на программу, которую хотите изменить.
2. Нажмите кнопку "Редактировать".
3. Внесите необходимые изменения.
4. Нажмите "Сохранить".

### Удаление программы

1. В расписании нажмите на программу, которую хотите удалить.
2. Нажмите кнопку "Удалить".
3. Подтвердите удаление.

## Мониторинг вещания

### Просмотр статистики вещания

1. Перейдите в раздел "Вещание".
2. Здесь вы увидите:
   - Текущий статус сервера
   - Количество слушателей
   - Текущий трек
   - Битрейт и другие технические параметры

### Прослушивание эфира

1. На странице "Вещание" нажмите кнопку "Слушать".
2. Или используйте встроенный плеер в нижней части экрана.

## Управление пользователями (только для администраторов)

### Создание нового пользователя

1. Перейдите в раздел "Настройки" → "Пользователи".
2. Нажмите кнопку "Добавить пользователя".
3. Заполните форму:
   - Email
   - Имя
   - Пароль
   - Роль (администратор, редактор, ди-джей)
4. Нажмите "Сохранить".

### Изменение прав пользователя

1. В списке пользователей найдите нужного пользователя.
2. Нажмите кнопку "Редактировать".
3. Измените роль пользователя.
4. Нажмите "Сохранить".

### Блокировка пользователя

1. В списке пользователей найдите нужного пользователя.
2. Нажмите кнопку "Заблокировать".
3. Подтвердите действие.

## Настройки системы (только для администраторов)

### Настройка Icecast

1. Перейдите в раздел "Настройки" → "Вещание".
2. Настройте параметры сервера, включая:
   - Пароли
   - Максимальное количество слушателей
   - Битрейт по умолчанию
   - Форматы вещания
3. Нажмите "Сохранить".
